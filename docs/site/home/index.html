它能做什么

不用手写 JSON UI

控件、排版、文字换行都写在 JavaScript 里，构建时生成游戏读取的 JSON 文件。

一个界面一个文件

显示什么、点了按钮做什么，都写在同一个 .screen.mjs 里。逻辑中可以直接调用 @minecraft/server。

先在浏览器里看

npm run dev 打开预览，保存后自动刷新。按钮、翻页和计时在预览里同样能用。

翻页与选项卡

多页用 Router，选项卡用 Tabs，跳转都用 Link、Back、Next。在同一个位置连续点「下一页」，每次都能翻过去。

会自己走的进度条

进度条由游戏客户端播放，计时期间不用重新打开表单。暂停、继续，或者关掉再打开，都从当前进度接着走。

在游戏里试过的规则

哪些写法在游戏里会出错，是做测试包一条条试出来的。构建时遇到这些写法会直接提示。

一个界面的全部代码

上面那个商店界面就是这些代码。它分三部分，运行的地方不一样：

  1. 1
    数据（props）
    行为包脚本打开界面时传进来，比如物品的名字和图标。
  2. 2
    逻辑（state、computed、methods）
    在游戏里运行，每个玩家一份。点按钮调用方法，状态变了界面就跟着更新。
  3. 3
    页面（page）
    只在构建时运行一次，生成 JSON UI，作用相当于 Vue 的模板。

开始用

1. 创建项目
npx bedrock-cui create my_ui cd my_ui npm install

会得到一个带示例小书的附加包项目。

2. 在浏览器里预览
npm run dev

改界面文件，预览会跟着刷新，静态检查也会给出提示。

3. 构建附加包
npm run build

生成资源包和行为包，在游戏里启用就能用。
