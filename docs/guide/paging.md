# 翻页

界面文件通过 `defineScreen()` 的 `pages` 声明多页内容，`layout` 声明各页共用的外框。页内通过 `link(页名)`、`next()`、`prev()`、`back()` 创建跳转按钮，完整示例见[页面](pages.md)。

## 服务端切换

点击跳转按钮时，表单关闭，bedrock-cui 以目标页重新打开表单，并恢复对应按钮的默认焦点，使鼠标不动时也能连续翻页。当前页没有对应方向的按钮时，框架自动加入的「原地不动」按钮接住点击。

重新打开仍有过渡，不能消除这段时间内点击落空的可能，见[更新显示](logic.md#更新显示)。仅在客户端切换的内容使用[选项卡](tabs.md)。

## 脚本端

翻页路由与表单按钮序号由 bedrock-cui 分配，无需脚本逐次处理。脚本只需通过 `界面.open(玩家, props)` 打开界面，见[界面文件](screens.md)。

界面打开期间，玩家的视角被锁定，关闭时解除。表单关闭与重新打开之间不要向聊天栏发送消息，否则界面可能消失数秒（真机），见[真机规则](reference/rules.md)。
