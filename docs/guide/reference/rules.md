# 真机规则

bedrock-cui 的排版、预览与静态检查所依据的游戏行为。各项规则通过测试附加包在 PC（Windows）与安卓（小米 14）上实际显示、截图逐像素比对得出。完整的测试记录见仓库的 `docs/DESIGN.md`。

## 界面挂载

| 规则 | 框架中的处理 |
|---|---|
| 原版 `server_form.json` 的 `main_screen_content` 尺寸为 0×0，挂载在其中的界面无法使用百分比尺寸。 | 挂载时将其与界面根控件设为 100%、左上锚点。 |
| 路由方式创建的界面，默认焦点不可靠；其中的百分比尺寸不按屏幕计算。 | 默认使用静态界面。 |

## 焦点与翻页

| 规则 | 框架中的处理 |
|---|---|
| 游戏只在鼠标移动时重新判断悬停的控件。 | 连续点击的翻页使用服务端翻页。 |
| 服务端重新打开表单时，点击交给默认焦点优先级最高的可见控件。 | 箭头由两个同序号按钮组成；「原地不动」按钮处理没有箭头的方向。 |
| 翻页期间向聊天栏发送消息，进入世界后的第一次翻页界面会消失数秒。 | `ServerPagesForm` 不发送消息。 |

## 叠放

| 规则 | 框架中的处理 |
|---|---|
| 层级相对父控件累加，层级高的控件绘制在上面。 | — |
| 同一层内按材质分批绘制：文字为一批，每种贴图各为一批；各批按其在控件树中首次出现的顺序绘制。 | 文字默认比图片高一层；预览按此规则绘制；静态检查 `text-covered`。 |

## 文字

| 规则 | 框架中的处理 |
|---|---|
| 游戏只在空格处换行。单词放得进一整行时整个移到下一行；比一整行还长时从当前行剩余位置逐字排列。PC 与安卓相同。 | `Paragraph` 默认软换行；静态检查 `engine-wrap-short-line`。 |
| 不换行空格（U+00A0）不作为断点；判断一行是否放得下时按 9 像素计算，绘制宽度为 4 像素。 | 软换行与折行模拟按此计算。 |
| 零宽空格（U+200B）、发丝空格（U+200A）显示为方框。 | 不使用。 |
| 8 像素高的字形在 10 像素高的行中垂直居中，比文字控件的顶端低 1 像素。 | 预览与行内图标按此对齐。 |
| `line_padding` 为 n 时，每一行（包括第一行）都多占 n 像素，文字在行内居中。 | `setLineSpacing()`；排版高度按此计算。 |
| 以 `#` 开头的文字整行不显示；以 `$` 开头的文字被当作变量；`§` 本身无法显示。 | 编译时自动处理 `#`、`$`。 |
| `§k` 与汉字在同一个文字控件中时，只显示为一串点。 | 静态检查 `obfuscated-unifont`。 |

## 字体与字宽

| | PC | 安卓 |
|---|---|---|
| 汉字字形 | GNU Unifont 点阵，双线性放大后按透明度阈值 0.35 绘制 | 平滑字体 |
| 字距 | 墨迹宽度 / 2 + 1；汉字 8.5 像素 | 全宽字符 9 像素 |
| 全角逗号 | 2 像素 | 9 像素 |
| 粗体每字增加（汉字） | 0.5 像素 | 1 像素 |
| 与 Unifont 字形不同的字符 | 48 个全角标点与符号（`src/font/gameGlyphs.ts`） | — |

框架中的处理：字宽档案 `pc` 与 `android`；静态检查按两种字宽各检查一次；分页与行内图标的折行按较宽的安卓字宽计算。

## 图片

| 规则 | 框架中的处理 |
|---|---|
| 九宫格图片小于边宽之和时，绘制范围超出控件，颜色变深。 | 静态检查 `nineslice-too-small`。 |
| 字形图（emoji 页）按 1:1 绘制，16 像素高，以文字行为中心；DDUI 不读取字形图。 | 字形图标配合 `setLineSpacing(6)`。 |
| 表单因点击而关闭、随即重新打开后，鼠标不动时的点击交给默认焦点；刚才点击的按钮若没有获得默认焦点，连续点击会落到别的按钮上（例如关闭按钮）。 | `button()` 内部是同一序号的普通版与聚焦版；重新打开时刚才点击的按钮获得默认焦点（与服务端翻页箭头相同）。 |
| 表单按钮的图标（`ActionFormData.button` 的第二个参数）可绑定到图片：原版物品、原版方块与附加包自己的贴图在 PC 与安卓上都能显示；按钮没有图标时图片隐藏。 | `form.buttonTexture`，编译方式与原版服务端表单的按钮图标相同。 |

## 脚本端

| 规则 | 框架中的处理 |
|---|---|
| 行为包脚本在 QuickJS 中解释执行。用 quickjs-emscripten 实测，速度约为 Node（V8）的十分之一，一次折行模拟约 0.65 毫秒。 | `softWrap()` 默认使用快速择优并缓存结果，单次 13–23 毫秒。 |
