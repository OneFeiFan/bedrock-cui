# 真机规则

编写界面时会遇到的游戏行为。各项规则通过测试附加包在 PC（Windows）与安卓上实际显示得出；排版、预览与静态检查都依据这些规则。

## 焦点与连续点击

| 规则 | 编写时 |
|---|---|
| 游戏只在鼠标移动时重新判断悬停的控件。 | 需要在同一位置连续点击的翻页，用页面（`Router`）；选项卡（`Tabs`）不适合（见[页面与选项卡](../pages.md#页面与选项卡)）。 |
| 表单因点击而关闭、随即重新打开后，鼠标不动时的点击交给获得默认焦点的控件。 | bedrock-cui 让刚才点击的按钮（或新页中动作相同的按钮）获得默认焦点，无需处理。 |
| 表单关闭与重新打开之间（页面跳转、点击按钮、刷新）向聊天栏发送消息时，进入世界后的第一次界面会消失数秒。 | 事件处理函数中不要向聊天栏发送消息。 |

## 叠放

| 规则 | 编写时 |
|---|---|
| 层级相对父控件累加，层级高的控件绘制在上面。 | — |
| 同一层内按材质分批绘制：文字为一批，每种贴图各为一批；各批按其在组件树中首次出现的顺序绘制。 | 保持文字的默认层级（比图片高一层）；静态检查 `text-covered` 提示被遮挡的文字（见[叠放](../layering.md)）。 |

## 文字

| 规则 | 编写时 |
|---|---|
| 游戏只在空格处换行。单词放得进一整行时整个移到下一行；比一整行还长时从当前行剩余位置逐字排列。PC 与安卓相同。 | 较长的文字用 `Paragraph`，运行期文字用 `softWrap()`（见[文字](../text.md)）。 |
| PC 与安卓的字宽不同，同一段文字在安卓上通常宽 5% 到 10%。 | 静态检查按两种字宽各检查一次（见[跨平台](../cross-platform.md)）。 |
| `line_padding`（`setLineSpacing()`）为 n 时，每一行（包括第一行）都多占 n 像素，文字在行内居中。 | 文字中有字形图标时设为 6。 |
| 以 `#` 开头的文字整行不显示；以 `$` 开头的文字被当作变量；`§` 本身无法显示。 | 构建时已知的文字，bedrock-cui 自动处理 `#`、`$`。 |
| `§k` 与汉字在同一个文字控件中时，只显示为一串点。 | 静态检查 `obfuscated-unifont`。 |

## 表达式

| 规则 | 编写时 |
|---|---|
| 绑定中的运算只有整数：除法是整数除法（`5 ÷ 2` 为 2），小数常数参与运算时结果仍是整数（`5 × 0.1` 为 0），小数文字转为数字后为 0。 | 需要小数的值（例如比例），让逻辑算好整数再传入（见[表达式](../bindings.md#限制)）。 |
| 数字比较的各种组合都正确。含文字比较（「包含」）的组合中，`or` 右边被 `not` 包住的文字比较、被 `not` 包住的组合、数字比较与文字比较写在同一个表达式里，结果错误。 | 静态检查 `text-logic` 提示这些组合；改为在逻辑中算好（`computed`）再显示。 |
| `>=`、`<=` 与 `and`、`or` 组合时结果错误。 | `gte()`、`lte()` 可以放心组合，bedrock-cui 已处理。 |
| 开关的状态变化后，同时读取界面数据的表达式不会重新计算。 | 一个表达式不要同时读取数据与开关的状态（静态检查 `mixed-sources`）。 |

## 图片

| 规则 | 编写时 |
|---|---|
| 九宫格图片小于边宽之和时，绘制范围超出控件，颜色变深。 | 静态检查 `nineslice-too-small`。 |
| 原版的 `textures/ui/white` 不是纯色：四周有 2 像素黑边，拉伸后两端各有一段黑色。 | 纯色用 `Texture.SOLID`。 |
| 表单按钮的图标可以显示原版物品、原版方块与附加包自己的贴图，PC 与安卓都可以。 | 图标由脚本决定时，使用带图标的数据（`type: Item`，见[数据（props）](../props.md)）。 |
| 字形图（emoji 页）按 1:1 绘制，16 像素高，以文字行为中心；DDUI 不读取字形图。 | 见[字形图标](../glyph-icons.md)。 |

## 脚本

| 规则 | 编写时 |
|---|---|
| 行为包脚本在 QuickJS 中解释执行，速度约为电脑上 Node 的十分之一。 | 逻辑中只做显示所需的计算（见[脚本端的性能](../performance.md)）。 |
