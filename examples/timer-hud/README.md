# 已验证显示基准

此示例恢复用户真机确认过的 V15 布局、接收器、标题通道和动画时钟。V17 的 actionbar 变量时长方案真机失败：UI 损坏、进度条未显示，已经从主示例和公开配置撤回。脚本模拟通过不代表原版客户端绘制正确。

`build.mjs` 在打包前将本示例生成的表单和计时 HUD 与 `tests/fixtures/timer-hud-v15.json` 比对。基准直接取自 V15 原始安装包，不由新编译结果自动刷新。

新的通道或动画实验应使用独立示例、独立的 RP/BP UUID、独立命令和安装包，不覆盖这个可用基准。先验证最小实验，再验证与稳定场景并用，得到真机确认后再考虑接入。普通代码修复只运行受影响的检查，无需每次重跑全量测试。

当前源码保留 V16 的标题排队 API，但主示例已恢复 V15 单标题时间线。交付的 `cui-live-probe-v15-recovery.mcaddon` 直接来自 V15 原始包，连脚本也保持原样；仅提高两份包清单的版本到 1.0.17，以覆盖 V17。
